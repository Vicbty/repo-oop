# OOP · AIDAMS 2A (B. Dallard)

Practical exercises for the OOP course.

## Contents

| Folder | Exercise | Gist |
|---|---|---|
| `oop_problems/operator_overloading.py` | Operator overloading: complex numbers, Person (`>`), Vector dot product (`*`), Circle comparisons, Point distance comparisons, matrix multiplication | OOP Problems |
| `oop_problems/inheritance.py` | Inheritance: Vehicle / Car / Bicycle, Person / Student / Employee, BankAccount / SavingsAccount | OOP Problems |
| `uml/hospital_management_system.md` | UML Exo 1: class diagrams (tasks 1-3), sequence diagram, system sequence diagrams, design questions | UML practice |
| `uml/abcd_records.md` | UML Exo 2: use case, class and sequence diagrams (levels 1-3) | UML practice |

## Run the code

```bash
cd oop_problems
python operator_overloading.py
python inheritance.py
```

Each file ends with small `assert` tests and prints a confirmation when they all pass.

## Diagrams

The UML diagrams are written in Mermaid and render directly on GitHub.
